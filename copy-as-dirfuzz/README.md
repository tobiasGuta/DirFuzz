# Copy as DirFuzz — Burp Suite Extension

A small Montoya API extension that adds **Copy as DirFuzz** to Burp Suite's HTTP context menu.

It does not send requests, launch DirFuzz, scan targets, or run anything in the background. It only converts the Burp request you selected into a DirFuzz CLI command and copies that command to the clipboard.

## Mapping

The converter follows the current DirFuzz CLI:

| Burp request data | DirFuzz output |
|---|---|
| Request URL | `-u` |
| Wordlist | `-w wordlists/common.txt` |
| HTTP method | `-m` (always emitted so DirFuzz does not fall back to HEAD/GET auto behavior) |
| User-Agent | `-ua` |
| Cookie | `-b` |
| Other request headers | repeated `-H` |
| Request body | `-d` |
| HTTP/2 request | `--h2` |
| `Host` | omitted because DirFuzz derives it from `-u` |
| `Content-Length` | omitted because DirFuzz calculates it |

A literal `{PAYLOAD}` already present in the Burp request is preserved exactly. The extension never invents a fuzz point.

For example, this Burp request:

```http
POST /api/users/{PAYLOAD} HTTP/1.1
Host: example.com
User-Agent: Mozilla/5.0
Cookie: session=abc
Authorization: Bearer token
Content-Type: application/json

{"id":"{PAYLOAD}"}
```

becomes a command shaped like:

```powershell
dirfuzz -u 'https://example.com/api/users/{PAYLOAD}' -w 'wordlists/common.txt' -m 'POST' -H 'Authorization: Bearer token' -H 'Content-Type: application/json' -ua 'Mozilla/5.0' -b 'session=abc' -d '{"id":"{PAYLOAD}"}'
```

## Install

1. In Burp Suite, open **Extensions → Installed**.
2. Click **Add**.
3. Choose **Java**.
4. Select `copy-as-dirfuzz-1.0.0.jar`.
5. Right-click an HTTP request in Proxy history, Repeater, Logger, or another Burp HTTP view.
6. Choose **Copy as DirFuzz**.
7. Paste the command into your terminal and review it before running it.

## Compatibility

- Burp Suite Community and Professional
- Montoya API `2026.4+`
- Java 17+

The project deliberately uses `registerContextMenuItemsProvider(...)`, the current Montoya context-menu API, and does not register HTTP handlers.

## Build from source

With Gradle installed:

```text
gradle clean test jar
```

The JAR is written under `build/libs/`.

## Notes

- The default wordlist is `wordlists/common.txt`, which is included in the DirFuzz repository. Change the copied command if your local wordlist lives elsewhere.
- Repeated ordinary headers are emitted as repeated `-H` options; DirFuzz's current map-based header configuration determines the final effective value. `Host` and `Content-Length` are generated by DirFuzz and are intentionally not copied as custom headers.
- The converter never changes DirFuzz's own fuzz-placement rules. For example, a `{PAYLOAD}` in a request body uses DirFuzz's body-fuzz behavior; a marker only in a custom header does not implicitly disable DirFuzz's normal URL path generation.
- On Windows the extension copies PowerShell-safe quoting. On Linux/macOS it uses POSIX-shell quoting.
